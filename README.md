# portfolio

Personal site for Oscar Nolen: software engineer building production data pipelines and AI agents in fintech. Next.js 16, React 19, Tailwind, framer-motion. Deployed on Vercel.

```bash
nvm use && npm install
cp .env.local.example .env.local   # optional: RESUME_DOC_ID for the live resume
npm run dev                        # http://localhost:3000
```

All copy lives in `src/content/`; see `CLAUDE.md` for the layout of the code and the rules the content follows.
